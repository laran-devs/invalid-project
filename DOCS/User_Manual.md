# Руководство пользователя: DataBridge

## 1. Назначение программы
DataBridge — консольная утилита для автоматизации конвертации, валидации, очистки и трансформации табличных данных. Позволяет связывать различные форматы файлов (CSV, JSON, XML, Excel, Parquet) без использования СУБД.

---

## 2. Установка и запуск

### 2.1. Требования к окружению
- Python версии 3.10 или выше.
- Менеджер пакетов `pip`.

### 2.2. Установка зависимостей
```bash
pip install -r requirements.txt
```

Или установка утилиты в окружение в режиме разработки:
```bash
pip install -e .
```
После этого команда `databridge` становится доступна глобально в терминале. При запуске без установки можно использовать `python main.py`.

---

## 3. Команды интерфейса (CLI)

### 3.1. Конвертация данных (`convert`)
Выполняет валидацию, очистку, трансформации и сохранение данных в целевой формат.

**Синтаксис**:
```bash
databridge convert <ВХОДНОЙ_ФАЙЛ> --to <ФОРМАТ> [--config <СХЕМА>] [--output <ВЫХОДНОЙ_ФАЙЛ>] [--report <ОТЧЕТ_HTML>]
```

**Параметры**:
- `file`: путь к входному файлу (`.csv`, `.json`, `.xml`, `.xlsx`, `.xls`).
- `--to`: целевой формат (`csv`, `json`, `xml`, `xlsx`).
- `--config`: путь к схеме валидации в формате YAML или JSON (по умолчанию: `schema.json`).
- `--output`, `-o`: путь для сохранения результирующего файла. Если не указан, файл сохраняется в `data/output/<имя>.<формат>`.
- `--report`, `-r`: опциональный путь для сохранения HTML-отчёта.

**Пример**:
```bash
databridge convert samples/input.csv --to json --config samples/schema.yaml --output samples/output.json
```

**Особенности работы**:
- Валидные строки сохраняются в результирующий файл.
- Невалидные строки автоматически отфильтровываются в файл `errors.csv` рядом с результатом.

---

### 3.2. Валидация данных (`validate`)
Проверяет файл по правилам схемы без конвертации формата.

**Синтаксис**:
```bash
databridge validate <ФАЙЛ> [--config <СХЕМА>] [--report <ОТЧЕТ_HTML>]
```

**Параметры**:
- `file`: файл для проверки.
- `--config`: схема JSON или YAML.
- `--report`, `-r`: путь для сохранения HTML-отчёта.

**Пример**:
```bash
databridge validate samples/invalid.csv --config samples/schema.yaml --report samples/report.html
```

---

### 3.3. Профилирование датасета (`stats`)
Собирает метаданные и рассчитывает статистику по колонкам датасета.

**Синтаксис**:
```bash
databridge stats <ФАЙЛ>
```

**Пример**:
```bash
databridge stats samples/input.csv
```

**Выводимые метрики**:
- Количество строк и колонок;
- Размер файла на диске и объём данных в оперативной памяти;
- По каждой колонке: тип данных, число непустых значений, процент пропусков, число уникальных значений;
- Для числовых колонок: минимальное (`min`), максимальное (`max`) и среднее (`avg`) значения.

---

## 4. Коды возврата CLI
- `0`: Успешное выполнение команды (при `validate` — все записи валидны).
- `1`: Ошибка выполнения (не найден файл, синтаксическая ошибка схемы, либо наличие невалидных записей при валидации).
