# Руководство по сценариям использования: DataBridge

## 1. Сценарий 1: Конвертация CSV в JSON с валидацией и маппингом

### Задача:
Имеется выгрузка пользователей `input.csv`. Требуется:
- Проверить корректность email, возраста и уникальности ID;
- Переименовать `name` в `full_name`, а `birth_date` в `dob`;
- Привести имена к верхнему регистру, а email к нижнему регистру;
- Сохранить валидные данные в `output.json`, а строки с ошибками выделить в `errors.csv`.

### Команда:
```bash
databridge convert samples/input.csv --to json --config samples/schema.yaml --output samples/output.json
```

### Исходные данные (`samples/input.csv`):
```csv
id,name,email,age,birth_date
1,Иван Иванов,ivan@mail.ru,25,1999-01-15
2,Мария Смирнова,maria.mail.ru,30,1994-05-20
3,Петр Кузнецов,petr@mail.ru,200,2000-03-10
4,,empty@mail.ru,22,2002-07-01
5,Анна Соколова,anna@mail.ru,abc,2001-11-11
```

### Результат (`samples/output.json`):
```json
[
  {
    "id": 1,
    "full_name": "ИВАН ИВАНОВ",
    "email": "ivan@mail.ru",
    "age": 25,
    "dob": "1999-01-15"
  }
]
```

### Файл ошибок (`samples/errors.csv`):
```csv
id,name,email,age,birth_date
2,Мария Смирнова,maria.mail.ru,30,1994-05-20
3,Петр Кузнецов,petr@mail.ru,200,2000-03-10
4,,empty@mail.ru,22,2002-07-01
5,Анна Соколова,anna@mail.ru,abc,2001-11-11
```

## 2. Сценарий 2: Валидация файла с генерацией визуального HTML-отчёта

### Задача:
Проверить входящий JSON-файл на соответствие правилам бизнес-логики и сгенерировать интерактивный отчёт для аналитиков.

### Команда:
```bash
databridge validate data/raw/invalid_json.json --config samples/schema.json --report report.html
```

### Вывод в консоль:
```text
Всего записей: 5
Успешно обработано: 3
Ошибок: 2
  - Строка 2: поле "email" не соответствует формату
  - Строка 4: поле "age" вне диапазона (200)
Отчёт сохранён: report.html
```
