# План тестирования: DataBridge

## 1. Цели и область тестирования
Цель плана — комплексная верификация корректности работы всех модулей утилиты DataBridge:
- Чтение разнородных форматов (CSV, JSON, XML, Excel, Parquet);
- Корректность работы движка валидации по всем типам правил;
- Точность применения трансформаций и маппинга столбцов;
- Разделение потоков валидных и невалидных строк;
- Генерация консольных отчётов и HTML-документов;
- Корректность работы интерфейса командной строки (CLI).

---

## 2. Тестовые сценарии (22 сценария)
